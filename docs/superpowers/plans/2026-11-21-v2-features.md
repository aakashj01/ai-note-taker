# Meeting Notes v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (owner chose in-session execution). Steps use `- [ ]`.

**Goal:** Ship the nine v2 features in `docs/2026-11-21-v2-features-design.md`, each pushed as it lands.

**Architecture:** Same static ES-module app. New pure modules (search, todos, backup, apilog, people) are unit-tested in Node. UI screens are covered by the Playwright e2e test. IndexedDB moves to version 2 (adds a `logs` store; old data untouched).

**Tech Stack:** Vanilla JS, IndexedDB, Gemini REST (streaming), `node --test`, fake-indexeddb, Playwright.

**Spec:** `docs/2026-11-21-v2-features-design.md`

## Global Constraints
- Every new meeting field is optional; meetings saved by v1 must render and process unchanged.
- No AI call for theme, search, to-dos, backup, or log/usage.
- The API key is never written to logs or backups.
- Each task ends green (`npm test`), bumps `APP_VERSION` + `sw.js` VERSION + the e2e version check, commits and pushes.
- New user-facing copy: sentence case, plain verbs, no all-caps labels.

## Review Focus
1. A v1 meeting without `type`, `bookmarks`, `extraSections` or `highlights` opens, copies and regenerates (Tasks 6–7 tests use v1-shaped fixtures).
2. A restore file that's malformed or from another app → a clear error and nothing changed (Task 4).
3. A restore of a meeting that's already on the phone keeps the phone's version (Task 4).
4. The log never contains the key, and audio is size-only even for a 10 MB inline body (Task 5).
5. Ask with no ready meetings → a message, no AI call (Task 9).

### Task 1: Theme switch
**Files:** `js/theme.js` (new), `index.html` (inline pre-paint script), `styles.css` (`:root[data-theme=dark]` mirrors the dark tokens; the media query applies only to `:root:not([data-theme=light])`), `js/ui/settings.js`. Test: e2e.
**Interfaces:** `applyTheme(choice: 'system'|'light'|'dark')` sets `document.documentElement.dataset.theme` (removed for system) and `localStorage['theme']` (try/catch).
- [ ] e2e `theme: choosing Dark sets data-theme=dark and survives reload` → RED → implement → GREEN → commit.

### Task 2: Search
**Files:** `js/search.js` (new), `js/ui/library.js`. Test: `tests/unit/search.test.js`, e2e.
**Interfaces:** `searchMeetings(meetings, query) → [{ meeting, snippet: { before, match, after } | null }]`. Empty query returns all with `snippet: null`. Matches title, summary, todos, ideas, extraSections items, highlights, transcript, speaker names. Snippet is ±40 chars around the first match.
- [ ] Unit tests: `matches transcript Hinglish case-insensitively`, `matches a speaker name`, `snippet centred on match`, `empty query returns all`, `no match returns []`.
- [ ] e2e: typing "deck" filters to the meeting and shows the snippet. RED → implement → GREEN → commit.

### Task 3: To-dos screen
**Files:** `js/todos.js` (new, pure), `js/ui/todos.js` (new), `js/app.js` (route `#/todos`), `js/ui/library.js` (toolbar button "To-dos"). Test: `tests/unit/todos.test.js`, e2e.
**Interfaces:** `collectTodos(meetings, { person, showDone }) → [{ meeting, items: [{ todo, index }] }]` (newest meeting first). `peopleFromTodos(meetings) → string[]` (display names, sorted, with "Unassigned" last when present).
- [ ] Unit: `open only by default`, `showDone includes done`, `filter by display name`, `unassigned bucket`, `v1 meeting without notes is skipped`.
- [ ] e2e: open To-dos, see "Send the deck", filter Rahul, tick it → the meeting shows it done. Commit.

### Task 4: Backup and restore
**Files:** `js/backup.js` (new), `js/db.js` (`listAllChunks(partIds)`), `js/ui/settings.js`. Test: `tests/unit/backup.test.js` (fake-indexeddb).
**Interfaces:** `buildBackup({ includeAudio }) → Promise<{ blob, count }>`, a JSON `{ app: 'meeting-notes', version: 1, exportedAt, meetings: [...], audio: { [partId]: { mimeType, data: base64 } } }`. `restoreBackup(file) → Promise<{ added, skipped }>`. Throws `Error('This is not a Meeting Notes backup.')` on bad JSON or a wrong `app`. The file name is always `meeting-notes-backup.json`. Settings uses `navigator.share({ files: [File] })` when `navigator.canShare({ files })`, else an `<a download>`. `setSetting('lastBackup', Date.now())`.
- [ ] Unit: `round-trips meetings and audio`, `without audio has no audio key`, `existing meeting kept on restore`, `rejects non-backup JSON`, `rejects garbage`.
- [ ] Commit.

### Task 5: API log and usage
**Files:** `js/apilog.js` (new), `js/db.js` (version 2, `logs` store keyPath `id` autoIncrement; `addLog`, `listLogs`, `clearLogs`, trimmed to 200), `js/process.js` + `js/ui/settings.js` (pass `fetch: loggedFetch`), `js/ui/log.js` (new, route `#/log`), `js/ui/settings.js` (usage section + daily-limit field). Test: `tests/unit/apilog.test.js`.
**Interfaces:** `summarizeRequest(url, init) → { method, model, action, body }`: the key header is dropped, `inline_data.data` becomes `"[audio 85 KB audio/mp4]"`, and a Blob body becomes `"[upload 3.2 MB]"`. `summarizeResponse(text) → { text, usage: { in, out, thoughts } | null }` (SSE or JSON). `createLoggedFetch({ fetch, save, now })` saves `{ at, request, status, ms, response | error }`. `usageToday(logs, now) → { [model]: { requests, tokens } }` counts generate calls since midnight America/Los_Angeles. `nextReset(now) → Date`.
- [ ] Unit: `key never logged`, `audio replaced by size`, `upload body summarised`, `SSE usage parsed`, `usage counts only today Pacific`, `failed request logged with error`.
- [ ] Commit.
